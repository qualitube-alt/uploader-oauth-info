Privacy Policy

Effective date: 20 September 2026. This policy describes the owner-operated QualiTube Uploader OAuth trial and this information website.

Information accessed and its purpose

The desktop app accesses authorised YouTube channel IDs and names; video IDs, titles, descriptions, tags, thumbnails, publication schedules, processing and restriction status; and the local video files selected by the operator. It uses this information to upload and schedule videos, display status, avoid duplicates, update metadata and perform operator-enabled blocked-video cleanup.

Authorisation and storage

OAuth client credentials and refresh tokens are stored in the operator’s local application data directory. The app uses them to obtain short-lived access tokens. Local settings, upload history, file paths, results and cached channel/video status remain on the operator’s computer until removed. The app does not send these records to an app-developer collection server.

Data transfers and service providers

Uploads and authorised API requests are sent to Google/YouTube using the selected Multilogin browser profile and its configured network connection. Multilogin and any proxy provider operate under their own policies. If AI metadata generation is enabled, selected video content and prompts are sent to Google Gemini using the configured API key. If optional notifications are configured, upload results may be sent to the operator’s chosen notification service. Those optional features are controlled in the app.

Limited Use

QualiTube Uploader’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used for the disclosed user-facing features, not sold or used for advertising. OAuth credentials are not published on this site or sent as notification content.

Retention, revocation and deletion

You may revoke access in Google Account connections. You may remove a channel’s stored authorisation in the app. Other local records can remain until you remove the relevant application data. Revoking access or deleting local records does not delete videos already stored on YouTube; manage those videos separately in YouTube Studio.

This website

This static information site is hosted by GitHub Pages. It has no sign-in form, advertising or application analytics. GitHub may process network and access information under its Privacy Statement.

Questions and updates

Privacy questions: contact the maintainer through GitHub Issues. Do not post passwords, tokens, private videos, or other confidential information in a public issue.

Changes to these practices will be reflected on this page with an updated effective date.
